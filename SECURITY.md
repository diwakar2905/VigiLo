# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.5.x   | :white_check_mark: |
| 3.0.x   | :x:                |
| < 3.0   | :x:                |

## Reporting a Vulnerability

VigiLo takes security and user privacy extremely seriously.

Please **DO NOT** report security vulnerabilities via public GitHub Issues.

To report a vulnerability:
1. Contact the security maintainers via confidential email or open a private GitHub Security Advisory.
2. Include a detailed description, proof-of-concept steps, and affected platform components.
3. We will respond within 48 hours and work with you to issue a patched release.
