Why VigiLo?

Engineered to Defender/Bitwarden security standards. Not a student project.

🔒

100% Local-First

Zero third-party cloud analytics, remote tracking servers, or telemetry egress. All evidence stays encrypted on your local hardware.

🚦

Deterministic State Machine

Strict scoping between DISARMED, WATCH MODE, and LOST MODE. Intrusive tools are strictly prohibited during normal local laptop use.

📜

Cryptographic Evidence

Every event compute a SHA-256 hash. Compiles legally admissible PDF forensic incident reports with device identity signatures.

Enterprise Platform Hardening

⚡ Instant 0.1s Intruder Detection

Hooks into native Windows Event ID 4625 (Failed Logon) for zero-latency camera capture without CPU polling.

🔑 DPAPI Device Identity Platform

Binds installation to hardware UUID, RSA keypair, and self-signed certificate stored in Windows DPAPI storage.

🛡️ Tamper Detection Engine

Monitors background services, scheduled tasks, registry keys, and binary hashes for unauthorized modification.

📬 Multi-Provider Notification Queue

Priority-queued delivery supporting Telegram, Webhooks, and fallback providers with exponential backoff retries.
